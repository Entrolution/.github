# Entrolution

Open-source developer tools.

## Projects

| Project | Description |
|---------|-------------|
| [Causantic](https://github.com/Entrolution/causantic) | Local-first long-term memory for AI coding tools. Causal graphs, hybrid BM25+vector search, self-benchmarking. |
| [Speed-Read](https://github.com/Entrolution/speed-read) | Lightweight, embeddable document reader for EPUB, PDF, and CBZ. One line to add a reader to any webpage. |
| [Codex Format Spec](https://github.com/Entrolution/codex-file-format-spec) | Open specification for a modern document format with semantic content, cryptographic integrity, and verifiable provenance. |
| [cdx-core](https://github.com/Entrolution/cdx-core) | Rust reference implementation for reading, writing, and validating Codex (.cdx) files. |
| [cdx-pandoc](https://github.com/Entrolution/cdx-pandoc) | Pandoc custom writer/reader for converting documents to and from Codex format. |
